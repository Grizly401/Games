# Консольные игры на C++: Tank, Tetris, Cosmo Desant

Три игровых проекта, реализующих классические игровые механики в консольном режиме.

## Общие игровые механики для всех проектов
- Объектно-ориентированное программирование (ООП)
- Система передвижения объектов
- Отрисовка игрового поля с использованием двумерных массивов
- Координатная система
- Механика столкновений (коллизии)
- Проверка границ игрового поля
- Система проверки возможности поворота объектов

## 🚀 Cosmo Desant - Космический десант
**Уникальные механики:**
- Генерация вражеских объектов
- Волновая система с повышением сложности после каждой пройденной волны
- Система подсчета и отображения очков

## Tetris - Классический тетрис
**Уникальные механики:**
- Удаление заполненных линий
- Автоматический перезапуск игры при достижении верхней границы поля
- Генерация случайных фигур

## Tank - Танковый бой
**Уникальные механики:**
- Режим для двух игроков
- Раздельное управление (WASD и стрелки)
- Система попаданий и уничтожения танков

## Установка и запуск

### Требования
- Windows 10/11
- Visual Studio 2022
- Поддержка C++17

### Инструкция по запуску
1. Клонировать репозиторий: git clone https://github.com/Grizly401/Games
2. Открыть .sln файл в VS2022
