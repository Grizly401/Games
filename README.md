# Консольные игры (Tetris, Tank, Cosmo Desant) 

 Проекты представляют собой классические 2D-игры, реализованные в консоли с использованием C++ и WinAPI для отрисовки и управления. Они разрабатывались с целью отработки ключевых аспектов программирования:
- Работа с памятью и двумерными массивами.
- Объектно-ориентированный подход (ООП).
- Обработка пользовательского ввода.
- Алгоритмы проверки столкновений.
- Управление игровой логикой и состоянием объектов.
